## Cách sử dụng
1. Mở file `index.html` trong trình duyệt
2. Chọn ảnh hoặc kéo thả file vào vùng upload
3. Click "Upload Ảnh"
4. Copy URL từ kết quả trả về

## Variants mặc định
- `public` - Ảnh gốc
- `avatar` - Ảnh avatar
- `header` - Ảnh header

## Giới hạn
- Kích thước file: Tối đa 10MB
- Định dạng: JPEG, PNG, GIF, WebP
